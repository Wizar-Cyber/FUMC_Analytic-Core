## 2. Actualización posterior: despliegue y verificación Azure

La tabla anterior documenta el estado de código y pruebas observado durante la auditoría de Fase 2; no se debe leer como estado actual de cada pendiente. En la verificación posterior del 2026-11-09 se comprobó que el despliegue Bicep `satfumc-prod` terminó `Succeeded`; la Function App Linux/Python 3.11 está `Running` y Azure indexó 33 funciones. Azure SQL `SATFUMCOperational` está `Online` y las nueve tablas de `sql_schema.sql` fueron aplicadas.

Easy Auth bloqueó las solicitudes anónimas (`401`) y el endpoint `/.auth/login/aad` redirigió (`302`) a Microsoft. No se validó un `200` autenticado, una ejecución de caso ni una integración AML→Functions. La Function App continúa usando Tables/Blob; el esquema SQL no está conectado al servicio. La última suite completa pasó 71 pruebas, en contraste con el conteo histórico de la tabla anterior.

### 2.1. Escala de generación y evaluación ML

La generación sintética sí terminó hasta 100.000 estudiantes en una carpeta temporal; el manifest final informa 552.847 snapshots, 485.421 etiquetas maduras y 2.394.881 filas de detalle de asignaturas. **No se entrenó ni evaluó el modelo a 100k.** A 50k también se completó generación sin run de modelo. Los runs MLflow disponibles corresponden a escalas 6k, 15k y 30k, además de variantes calibradas/prevalencia; sus Recall/precisión/F1/AUC y tasa de alertas difieren según versión, split y calibración. Están resumidos por separado en [`ScaleExperiments.md`](./ScaleExperiments.md), con hashes, conteos y flags de promoción.

## 3. Decisiones de seguridad de ejecución

- No se ejecutará un entrenamiento apuntando a `data/raw/`, `models/`, `outputs/` o el `mlruns/` existente. Los experimentos nuevos usarán directorios temporales.
- No se conectarán fuentes institucionales, no se desplegará Azure y no se llamará GPT/AML remoto durante pruebas locales.
- Las corridas de generación 50k/100k se conservaron fuera del repositorio; no hubo entrenamiento ML a esas escalas. Los resultados detallados están en [`ScaleExperiments.md`](./ScaleExperiments.md).
