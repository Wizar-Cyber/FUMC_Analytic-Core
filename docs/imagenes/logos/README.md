# Logos de tecnologías

Iconos usados por `docs/diagramas/build_diagrams.py`. Proceden del paquete de código abierto [`diagrams`](https://github.com/mingrammer/diagrams) (licencia MIT), que redistribuye:

- **Azure Architecture Icons** de Microsoft (Functions, Service Bus, Storage, SQL Database, Azure OpenAI, AI Search, Azure Machine Learning, Application Insights, Log Analytics, Entra ID, Managed Identity, Key Vault, Resource Group, App Service Plan). Microsoft permite su uso en diagramas de arquitectura; no deben recortarse, distorsionarse ni alterarse.
- Logos de proyectos de código abierto o marcas (Python, JavaScript, GitHub, GitHub Actions, Git, MLflow) para representar la tecnología en diagramas técnicos.

Las tecnologías sin icono oficial en este conjunto (LightGBM, XGBoost, scikit-learn, SHAP, Semantic Kernel, Bicep, Azure Durable Functions) se muestran como etiqueta de texto; no se fabrican logos.
